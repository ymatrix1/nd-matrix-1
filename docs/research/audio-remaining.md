# Audio parity: what is still open (consolidated list)

- **Checked:** 2026-11-17
- **Sources:** merged PRs #370 to #440 (decisions D72 to D116 are on `main`), the research notes cited per row, `docs/OPEN-QUESTIONS.md`, `docs/ROADMAP.md`, `docs/TECH_DEBT.md`, [emulation-coverage](emulation-coverage.md) (subsystem table, counts), the Part A demo video comparisons (`docs/research/data/emu_vs_hw_segments.json`, 22 segments) and a listening test of 2026-11-15 (Velvet Grand A:61, Felt Upright A:13).
- **Question:** which audio items still stand between the emulator and 1:1 parity with the hardware, with what state, difficulty, audible impact and hardware need, and which PRs and decisions touched each?

Each row names the ROADMAP item it belongs to (`7b.N` = Phase 7b section N; the progress per phase is in [emulation-coverage](emulation-coverage.md) 2.1). Tags: **VERIFIED** = matches firmware or oracle, **EMPIRICAL** = fitted to a recording, **ASSUMED** = chosen without evidence. A default flips only when verified end to end (D22). Difficulty (low / medium / high) and impact (low / medium / high) are estimates (ASSUMED). Hardware column: **none** = the ARM harness, the SHARC oracle or a listening test can close it; **clip** = a hardware recording is needed; **both** = the oracle first, a clip to confirm.

PR links are `https://github.com/ymatrix1/nord-stage-4-emulator/pull/N`; written here as `#N`. "open" = not merged.
